# Power BI Data Modeling Project

## 📊 Project Overview

This project demonstrates the use of **Microsoft Power BI for data modeling, data transformation, and business analysis**.

The project focuses on creating a structured data model from raw data, establishing relationships between tables, and developing an interactive Power BI report.

---

## 🎯 Project Objectives

- Understand data modeling concepts in Power BI
- Transform and prepare data using Power Query
- Create relationships between multiple tables
- Understand primary keys and foreign keys
- Implement relationship cardinality
- Build a structured data model using fact and dimension tables
- Create DAX measures for analysis
- Develop an interactive Power BI report

---

- **Microsoft Power BI Desktop**

## 🧩 Data Modeling

The project demonstrates how to create a structured data model in Power BI by connecting different tables using appropriate relationships.

- Key Concepts
- Fact Tables
- Dimension Tables
- Primary Keys
- Foreign Keys
- One-to-Many Relationships
- Cardinality
= Cross-Filter Direction
- Table Relationships
- Star Schema
- Data Model

## 🔄 Data Transformation

Power Query was used to prepare and transform the source data before creating the data model.

The transformation process includes:

1. Data cleaning
2. Removing unnecessary columns
3. Changing data types
4. Renaming columns
5. Preparing tables for analysis
6. Handling data inconsistencies
   
## 📐 DAX

DAX was used to create calculations and measures required for the analysis.

The project demonstrates concepts such as:

- Measures
- Aggregations
- Calculated values
- Filter context
- KPI calculations
  
## 📈 Power BI Dashboard

An interactive Power BI report was created to visualize and analyze the data.
